# auth — usuario

## ¿Qué es?
Es la puerta de entrada a UCI Link: registrarte y entrar con tu cuenta.

## Registrarte (nuevo usuario)
1. Pulsa **Registrarse** y elige tu tipo de cuenta: **Aspirante** o **Empresa**.
2. Escribe un email válido y una contraseña de **mínimo 8 caracteres**.
3. Recibes una sesión lista para usar. El sistema te llevará a completar tu **perfil**
   (obligatorio antes de publicar).
4. Si el email ya existe verás "El email X ya está registrado" — entonces **inicia sesión**.

## Iniciar sesión
1. Pulsa **Entrar**, escribe email y contraseña.
2. Si no recuerdas si estás suspendido: verás el aviso "El usuario está suspendido...".
3. Comunes: "Email o contraseña incorrectos" significa que alguno de los dos no coincide.

##admin
Las cuentas de administrador NO se crean por la web: solo por semilla interna. Si te hace
falta un rol admin, contacta al equipo de operación.

## Preguntas frecuentes
- **¿Puedo ser aspirante y empresa con un mismo email?** No. Un email(es) = una cuenta con un rol.
- **¿Qué pasa si cierro sesión?** Tu token se borra del navegador; tus datos siguen a salvo.
