# aspirante — usuario

## ¿Qué es?
Tu tarjeta de presentación: datos personales, carrera, habilidades y links (LinkedIn, GitHub, portafolio).

## Crear tu perfil (primer paso tras registrarte)
1. Después de registrarte, el sistema te pide completar tu perfil.
2. Rellena **nombre** y **apellido** (obligatorios).
3. Opcional: teléfono, carrera, semestre (1-12), bio, lista de habilidades, y URLs de LinkedIn/GitHub/portafolio.
4. "Guardar". Si ves "El usuario ya tiene un perfil", ya lo creaste antes: usa editar.

## Editar tu perfil
1. Entra desde el header a **Mi perfil**.
2. Cambia lo que quieras y guarda. Lo que no toques, permanece igual.

## Consejos
- Pon 5-10 habilidades ("React", "SQL", "Figma"...): las empresas filtran por ahí.
- La bio breve y directa: qué estudias, qué buscas.
- Tus links deben ser URLs completas (https://...).

## ¿El perfil es público?
Sí — cuando publiques currículums, empresas (y otros aspirantes) pueden ver tu
perfil y valorarlos. Tu teléfono solo se muestra si lo completaste.
